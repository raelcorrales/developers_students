# Solución para la Suma Máxima de una Matriz sin Compartir Fila ni Columna

Se generaron implementaciones para encontrar la suma máxima seleccionando un elemento por fila y columna sin colisiones. Pregunta de Stripe.

## Descripción del Problema

Dada una matriz cuadrada de enteros $N \times N$, calcula la máxima suma posible de $N$ elementos de tal manera que no haya dos elementos en la misma fila ni en la misma columna.

### Ejemplo

Entrada:
```python
matrix = [
    [3, 1, 2],
    [4, 5, 6],
    [-7, 8, 9]
]
```
Salida: `17` (3 + 6 + 8)
