# Solución para la Suma de Múltiplos de FizzBuzz

Se generaron dos implementaciones para encontrar la suma de todos los múltiplos de 3 o 5 estrictamente menores a un valor objetivo `target`. Pregunta de Google.

## Descripción del Problema

Dado un número entero positivo `target`, calcula la suma de todos los números menores a `target` que sean divisibles entre 3 o entre 5.

### Ejemplo

Entrada: `target = 10`
Múltiplos: `3, 5, 6, 9`
Salida: `23` (3 + 5 + 6 + 9)
