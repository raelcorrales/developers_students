# Solución para Intersección de Dos Listas

Se generaron dos implementaciones para encontrar los elementos comunes presentes en dos listas, sin duplicados. Pregunta clásica de entrevista (Apple).

## Descripción del Problema

Dadas dos listas de enteros `a` y `b`, devuelve una lista que contenga la intersección de ambas listas (elementos que aparecen en ambas). Cada elemento en el resultado debe ser único.

### Ejemplo

Entrada:
```python
a = [1, 2, 3, 4, 5]
b = [0, 1, 3, 7]
```

Salida:
```python
[1, 3] # o [3, 1]
```
