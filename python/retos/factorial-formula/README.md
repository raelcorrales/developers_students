# Solución para el Cálculo del Factorial

Se generaron dos implementaciones para calcular el factorial de un número $n! = n \times (n-1) \times \dots \times 1$. Pregunta clásica de Microsoft.

## Descripción del Problema

Dado un número entero no negativo `n`, devuelve el valor de `n!`. Por convención, `0! = 1`.

### Ejemplo

Entrada: `n = 5`
Salida: `120`
